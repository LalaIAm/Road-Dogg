# Product: RoadDoggs

RoadDoggs is an AI-powered road trip planning web app. Users configure a trip with an origin, destination, travel dates, themed preferences (e.g. Scenic, Historical, Kid-Friendly), pacing limits, and accommodation preferences. An AI engine generates a curated itinerary with stops, drive times, and lodging recommendations. Users can customize stops via drag-and-drop, save and retrieve trips, share itineraries via link or direct user invite, and export to PDF.

## Key Concepts

- **Trip**: Origin + destination + dates + preferences → AI-generated itinerary
- **Leg**: A single day's driving segment between overnight stops
- **Stop**: A point of interest along the route with a preference tag and description
- **Accommodation**: Lodging recommendation per leg with outbound booking links (no in-app booking)
- **Pacing**: Max daily driving distance (Leisurely/200mi, Moderate/350mi, Aggressive/500mi, or custom)
- **Sharing**: View-only or edit access via shareable link or direct user grant
